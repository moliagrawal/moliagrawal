### About

I build systems that hold up under real conditions — smart contracts, decentralised storage, autonomous machines, and the infrastructure that keeps all three reliable. Currently working through **Road to Devcon**, building reentrancy-safe escrow contracts and on-chain attestation registries in Solidity.

```yaml
current_focus: Road to Devcon — reentrancy-safe escrow contracts & on-chain attestation registries
domains: Full-Stack, Web3, Autonomous Systems, Security Engineering
recent_work: CTF competition platforms, IPFS networks, autonomous pathfinding, IoT systems
approach: correctness under real-world failure conditions — restarts, reorgs, edge cases
```

- **Current work**: reentrancy-safe escrow contracts, zero-duplicate blockchain event watchers, and peer-to-peer storage systems.
- **Core strengths**: smart contract security patterns (checks-effects-interactions), EVM state machines, C++ pathfinding algorithms, and modern frontend architecture.
